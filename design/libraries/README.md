# Visual Libraries Bank

Niche libraries for making designs feel crafted rather than generic ("un-slopping" AI designs). Saved from the "10/10 niche GH libraries" series, parts 2 and 3.

> Check the licence, bundle size and browser support (WebGPU especially) before adding any of these to a production page. Always provide a static fallback and respect `prefers-reduced-motion`.

## Shaders, WebGL and WebGPU effects
| Library | What it does | Link | Good for |
|---|---|---|---|
| **Liquid Logo** | Turns any logo into liquid chrome/metal using Paper Shaders | liquid.paper.design | Hero logo, brand intro, splash screen |
| **WebGL Fluid** | Fluid simulation that follows the cursor | github.com/PavelDoGreat/WebGL-Fluid-Simulation | Playful hero backgrounds, interactive moments |
| **Shader Lab** | "Photoshop for shaders": a visual shader editor | _link to confirm_ | Designing custom background or texture shaders without hand-writing GLSL |
| **GL Transitions** | 100+ GPU transitions between images or slides | github.com/gl-transitions/gl-transitions | Galleries, slideshows, page transitions |
| **vgpu** | Modular WebGPU library for shaders, 3D scenes, GPU tensors, neural nets and math visualisation, built for AI agents | vgpu.sh | Advanced GPU visuals and data/maths visualisation |
